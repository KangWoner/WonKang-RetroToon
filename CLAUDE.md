## Project Overview

WonKang-RetroToon is a TypeScript project initialized with Jest testing, ESLint, and a basic build pipeline. The project is in early stages with minimal implementation.

## Development Commands

```bash
# Build the project (compiles TypeScript to dist/)
npm run build

# Run tests (uses Jest with ts-jest, runs sequentially)
npm test

# Lint TypeScript files
npm run lint

# Start the application (runs compiled code from dist/)
npm start
```

## Project Structure

```
src/          - TypeScript source files
dist/         - Compiled JavaScript output (generated by tsc)
```

## TypeScript Configuration

- **Target**: ES2020 with CommonJS modules
- **Strict mode**: Enabled with additional strictness options:
  - `noUncheckedIndexedAccess`
  - `exactOptionalPropertyTypes`
- **Build outputs**: Source maps, type declarations, and declaration maps are generated
- **Source root**: `src/`
- **Output directory**: `dist/`

## Testing

- **Framework**: Jest with ts-jest preset
- **Environment**: Node
- **Execution**: Tests run sequentially (`--runInBand` flag)
- **Test files**: Use `.test.ts` suffix in the `src/` directory

## Important Notes

- This is an early-stage project with minimal implementation
- No ESLint configuration file exists yet; linting relies on package defaults
